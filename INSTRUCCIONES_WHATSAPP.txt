═══════════════════════════════════════════════════════════════
   SYNAPSE — GUÍA PASO A PASO PARA CONECTAR WHATSAPP
   Tutor IA Socrático por WhatsApp usando Twilio + Gemini
═══════════════════════════════════════════════════════════════

REQUISITOS PREVIOS:
  ✓ Node.js instalado (v18+)
  ✓ API Key de Gemini (https://ai.google.dev/)
  ✓ Cuenta de Twilio (https://www.twilio.com — se puede usar Free Trial)
  ✓ Proyecto de Synapse con npm install ya hecho

═══════════════════════════════════════════════════════════════
PASO 1: CREAR CUENTA EN TWILIO (Gratis)
═══════════════════════════════════════════════════════════════

1. Ve a https://www.twilio.com/try-twilio
2. Regístrate con tu correo electrónico.
3. Verifica tu número de teléfono personal.
4. Una vez dentro del Dashboard de Twilio, anota:
   - Account SID  (empieza con "AC...")
   - Auth Token   (clic en "Show" para verlo)
   Estos están en la página principal del Dashboard.

═══════════════════════════════════════════════════════════════
PASO 2: ACTIVAR EL SANDBOX DE WHATSAPP EN TWILIO
═══════════════════════════════════════════════════════════════

1. En el Dashboard de Twilio, ve al menú izquierdo:
   Messaging → Try it out → Send a WhatsApp message

2. Te aparecerá una pantalla con instrucciones para el Sandbox.
   Verás un número de WhatsApp de Twilio (generalmente +1 415 523 8886)
   y un código tipo: "join xxxxx-xxxxx"

3. Desde tu teléfono personal:
   - Abre WhatsApp
   - Agrega el número +1 415 523 8886 a tus contactos
   - Envíale el mensaje: join xxxxx-xxxxx
     (usa el código exacto que te da Twilio)
   - Recibirás un mensaje de confirmación

   ¡LISTO! Tu WhatsApp personal ya está conectado al Sandbox.

═══════════════════════════════════════════════════════════════
PASO 3: CONFIGURAR LAS VARIABLES DE ENTORNO EN SYNAPSE
═══════════════════════════════════════════════════════════════

1. En la carpeta del proyecto Synapse, copia el archivo de ejemplo:

   copy .env.example .env

2. Abre el archivo .env y llena los valores:

   PORT=3000
   NODE_ENV=development
   GEMINI_API_KEY=tu_api_key_de_gemini_aqui
   FIREBASE_CREDENTIALS_PATH=./firebase-credentials.json
   TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TWILIO_WHATSAPP_NUMBER=whatsapp:+14155238886

   NOTA: El TWILIO_WHATSAPP_NUMBER es el número del Sandbox
   (el mismo al que le mandaste el "join").

═══════════════════════════════════════════════════════════════
PASO 6: CREAR UN TÚNEL PÚBLICO (para que Twilio pueda 
        alcanzar tu servidor local)
═══════════════════════════════════════════════════════════════

Twilio necesita una URL pública para enviar los mensajes de
WhatsApp a tu servidor. Tienes 2 opciones:

── OPCIÓN A: LocalTunnel (Gratis, más fácil) ──

Abre OTRA terminal (sin cerrar la del servidor) y ejecuta:

   npm run tunnel

O directamente:

   npx -y localtunnel --port 3000 --subdomain synapse-tutor

Te dará una URL como:
   https://synapse-tutor.loca.lt

IMPORTANTE: La primera vez que abras esa URL en el navegador
te pedirá ingresar tu IP. Eso es normal, solo dale continuar.

── OPCIÓN B: ngrok (Más estable, requiere cuenta gratuita) ──

1. Descarga ngrok: https://ngrok.com/download
2. Crea cuenta gratuita y copia tu authtoken
3. Ejecuta:
   ngrok config add-authtoken TU_TOKEN_AQUI
   ngrok http 3000

Te dará una URL como:
   https://abc123.ngrok-free.app

═══════════════════════════════════════════════════════════════
PASO 7: CONECTAR EL WEBHOOK EN TWILIO
═══════════════════════════════════════════════════════════════

1. Copia tu URL pública del paso anterior (la de localtunnel
   o ngrok) y agrégale la ruta del webhook:

   https://TU-URL-PUBLICA/api/webhook/whatsapp

   Ejemplo con localtunnel:
   https://synapse-tutor.loca.lt/api/webhook/whatsapp

   Ejemplo con ngrok:
   https://abc123.ngrok-free.app/api/webhook/whatsapp

2. Ve a Twilio Console:
   Messaging → Try it out → Send a WhatsApp message
   
3. En la sección "Sandbox Configuration" (o haz clic en
   "Sandbox settings" en la parte inferior):
   
   - En el campo "WHEN A MESSAGE COMES IN":
     Pega tu URL:  https://TU-URL-PUBLICA/api/webhook/whatsapp
     Método: HTTP POST

   - En el campo "STATUS CALLBACK URL" (opcional):
     Déjalo vacío por ahora.

4. Haz clic en "Save".

═══════════════════════════════════════════════════════════════
PASO 8: ¡PROBAR! 🎉
═══════════════════════════════════════════════════════════════

Ahora ve a tu WhatsApp personal y envíale un mensaje al
número del Sandbox de Twilio. Prueba estas cosas:

  1. TEXTO: "No entiendo las ecuaciones cuadráticas"
     → Synapse te guiará con método socrático

  2. NOTA DE VOZ: Graba tu duda hablando
     → Synapse transcribe y te hace preguntas de repaso

  3. FOTO: Tómale foto a un ejercicio de tu cuaderno
     → Synapse analiza y señala dónde está el error

  4. Escribe "quiz"
     → Synapse te genera un examen rápido de 3 preguntas

  5. Escribe "ayuda"
     → Muestra el menú de opciones disponibles

  6. Escribe "reiniciar"
     → Limpia la conversación para empezar tema nuevo

═══════════════════════════════════════════════════════════════
NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════

⚠️ SANDBOX vs PRODUCCIÓN:
   - El Sandbox es GRATUITO pero temporal. Si no envías
     mensajes en 72 horas, se desconecta y hay que volver
     a enviar el "join".
   - Para producción (número propio), necesitas aprobar tu
     cuenta de Twilio y solicitar un número de WhatsApp
     Business. Esto cuesta ~$15 USD/mes.

⚠️ TÚNEL:
   - Si usas localtunnel, la URL puede cambiar al reiniciar.
     Si cambia, actualiza el webhook en Twilio.
   - Si usas ngrok free, la URL cambia cada vez que reinicias
     ngrok. Actualiza en Twilio cada vez.

⚠️ LÍMITES DEL FREE TRIAL DE TWILIO:
   - Twilio te da ~$15 USD de crédito gratuito.
   - Cada mensaje de WhatsApp cuesta ~$0.005 USD.
   - Eso alcanza para ~3,000 mensajes de prueba.

⚠️ FIREBASE (OPCIONAL POR AHORA):
   - El backend funciona sin Firebase (usa mock data).
   - Para persistencia real, descarga tu firebase-credentials.json
     desde Firebase Console → Project Settings → Service Accounts
     → Generate New Private Key.
